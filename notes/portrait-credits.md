# Portrait credits

Every real portrait in `site_src/portraits/` gets a line here before it goes
in. The site is public and forkable; art with an unclear licence would make it
undistributable, which defeats the point of the project.

## Safe sources

- **Raja Ravi Varma** (1848–1906) — public domain. Painted many Mahabharata
  subjects; Wikimedia Commons has good scans. The reference style descends
  from him, so it already matches.
- **Pre-1930 Indian oleographs** (Chitrashala Press and others) — generally
  public domain in India (life + 60 years). Verify each item.
- **Art generated for this project** — note the tool and the date.

## Not usable

Amar Chitra Katha, Gita Press, modern film and TV art, and anything else
still in copyright — however easy it is to find.
