# సంపూర్ణ మహాభారతము

A Telugu retelling of the Mahabharata in simple modern prose, one parva at a
time, with an illustration for every story and a portrait for every character.

Built as a first door — the place a child starts and trusts — with clear
signposts out to the Kavitrayam's verse, the critical edition, and whatever
copy sits on the family shelf. It does not claim to replace any of them.

**Live site:** enable GitHub Pages on `main` / root (see *Deploying* below).

| **Next** | ఆది పర్వము batch two (Śakuntalā, Yayāti) |

Every episode carries two things besides the story itself:

- **మూలంలో** — where the episode sits in Vyasa's text (which upa-parva, and
  where confident, which adhyāyas), and where to find it in the Kavitrayam's
  Andhra Mahabharatam (which āśvāsa). This is what lets a reader move from
  this prose to the verse without getting lost.
- **నేర్చుకున్నది** — a short reflection at the end, written for a child who
  has just finished the story.

## The source

The primary source is **శ్రీమదాంధ్ర మహాభారతము** — the Kavitrayam's Andhra
Mahabharatam rendered into modern Telugu prose — read directly, page by page.
It is the Telugu tradition's own text, and its structure is what this site's
`మూలంలో` notes point at.

The site is an **independent retelling**, not a transcription: the prose here
is written fresh for children, and no passage is reproduced from that book.
What is taken from it is what belongs to the tradition rather than to any
publisher — the sequence of episodes, the names, the details of who did what,
and the source's own reference tables.

Its structure corroborates the references: Adi Parvam has eight āśvāsas there,
exactly as the `మూలంలో` notes claim, and its list of the hundred upa-parvas
groups onto its own per-parva counts without a discrepancy.

### A note on adhyāya numbers

Chapter numbers differ between the Bhandarkar Oriental Research Institute
(Pune) critical edition and the vulgate recensions in common circulation.
They are given only where they can be stated with confidence, and left out
otherwise. Naming the upa-parva is always reliable; naming a chapter is not.
Saying less is better than saying it precisely and wrongly.

## Built to last

The whole point is that this still opens in thirty years.

- Plain HTML, CSS and JavaScript. No framework, no bundler, no npm install.
- No server. `index.html` opened from a disk works exactly like the live site.
- No external runtime dependencies. Google Fonts is the only network request,
  and the CSS falls back to system Telugu fonts if it never answers.
- Everything generated — illustrations, portraits, emblems — is generated by
  scripts in this repo from a fixed random seed, so it can be regenerated
  byte-for-byte. Nothing came from a service that might disappear.
- `Mahabharatam_preview.html` is the entire site as one self-contained file
  with every image inlined. Mail it, print it, put it on a drive.

## Repository layout

```
site_src/            the authored source — edit only here
  parvas.json        the 18 parvas, their summaries and publication status
  <parva>.json       one file per parva: intro, episodes, closing
  characters.json    GENERATED by draw_icons.py — do not hand-edit
  gurus.json         teacher lineage page
  evolution.json     how the text grew page
  app.js, style.css  the site itself
  favicon.svg
  img/               episode illustrations, 1200x675 jpg
  icons/             character portraits and parva emblems, 256px png

build_site.py        site_src/ -> the repo root, plus the single-file preview
draw.py              generates every episode illustration
draw_icons.py        generates every portrait and emblem, and characters.json

index.html           GENERATED — the deployable site lives at the repo root
assets/ data/ img/ icons/ favicon.svg      GENERATED
```

`build_site.py` replaces only `data/`, `assets/`, `img/`, `icons/`,
`index.html` and `favicon.svg`. It never touches `site_src/`, the scripts, or
this README.

## Working on it

The drawing scripts need Pillow; nothing else needs anything.

```bash
python3 -m venv venv && ./venv/bin/pip install Pillow
```

Then:

```bash
./venv/bin/python draw_icons.py   # only if characters changed
./venv/bin/python draw.py         # only if illustrations changed
python3 build_site.py             # always, to publish your edits
```

To preview locally:

```bash
python3 -m http.server 8731
```

Hard-reload the browser after a rebuild — `data/*.js` caches aggressively.

### Episode shape

```json
{
  "num": 9,
  "title": "గరుత్మంతుడు — తల్లి దాస్యాన్ని తెంచిన రెక్కలు",
  "image": "09_garuda.jpg",
  "caption": "...",
  "characters": ["గరుత్మంతుడు", "వినత", "ఇంద్రుడు"],
  "paras": ["...", "..."],
  "learning": "...",
  "source": {
    "ref": "ఆది పర్వము — ఆస్తీక పర్వము (గరుడోపాఖ్యానము)",
    "adhyaya": "౨౦–౩౪",
    "kavitrayam": "నన్నయ — ఆంధ్ర మహాభారతము, ఆది పర్వము, ప్రథమాశ్వాసము",
    "note": "..."
  }
}
```

`learning` and `source` are optional and every field inside `source` is
optional — an episode without them still renders. Image filenames are numbered
to match the episode number; keep it that way.

Names in `characters` are matched against `characters.json` by name or alias.
An unmatched name still renders, just without a portrait or a link — so a new
character is a missing portrait, never a broken page. Add real ones to the
`CHARS` list in `draw_icons.py` and re-run it.

### Adding a parva

1. Write `site_src/<id>.json` in the same shape as `adi.json`.
2. Add illustrations: a scene function in `draw.py`, added to its `SCENES` list.
3. Add any new characters to `CHARS` in `draw_icons.py`.
4. Set that parva's `status` to `"published"` in `site_src/parvas.json`.
5. Run the three commands above.

## Deploying

The repo root *is* the site, so GitHub Pages needs no build step:

**Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`**

The same folder works unchanged on Netlify, Cloudflare Pages, or any static
host, or from a plain directory on a disk.

## Where this is going

Complete rather than condensed. The upakhyanas are the stories grandparents
tell and children later go looking for, so they belong in. Roughly 45 episodes
for Adi Parva and around 350 across all eighteen — a year-scale project, done
in batches, right rather than fast.

- [x] **Adi Parva, batch one** — Paushya, Pauloma and Astika (episodes ౧–౧౩),
      including the Andhra Mahabharatam's own Nannaya frame and the Sarama
      curse that opens the hundred upa-parvas
- [x] **మూల నిర్మాణము** — the 100 upa-parvas and the source's count tables
- [ ] **Adi Parva, batch two** — Adivamshavatarana and Sambhava in full:
      Dushyanta and Shakuntala, Yayati and Puru, Vasishtha, Kacha and
      Devayani. These currently sit compressed inside episode ౧౪.
      Source pages 25–109 of the PDF (āśvāsas 2–3).
- [ ] **Adi Parva, batch three** — Sambhava through Khandava expanded;
      episodes ౧౫–౨౦ rewritten at the same density as batch one
- [ ] Sabha Parva
- [ ] A glossary of names and terms
- [ ] A family tree that grows as characters appear
- [ ] Plain-text and printable PDF of every story
- [ ] Read-aloud audio
- [ ] Transliteration alongside the Telugu, for children who speak the
      language but cannot yet read the script

## Sources and where to go next

This retelling follows the Vyasa order as the Kavitrayam rendered it. It is a
starting point, not a substitute. Go on to:

- **నన్నయ, తిక్కన, ఎర్రన** — the Andhra Mahabharatam. The Telugu the whole
  tradition is built on, the reason this site marks āśvāsas, and the primary
  source read for this retelling.
- **BORI critical edition** (Bhandarkar Oriental Research Institute, Pune) —
  the scholarly reconstruction, and the reference point for chapter numbering.
- **Kisari Mohan Ganguli's English translation** — complete and public domain.
- Whatever Mahabharatam is already in the house. That copy has the advantage
  of being the one someone in the family actually read.

Independent Telugu prose based on Vyasa's Mahabharatam. All illustrations and
portraits are generated by the scripts in this repository.
